🧩 官方 Chrome 插件
小句子
随手收集，一键变课程
浏览英文网页、看 YouTube / Bilibili 视频时，选中任意单词或句子， 一键收集到句游英语，自动转化为你的私人课程包，随时学习。
📥 Chrome
★★★★★ 4.9 · 12,860 人安装
✨ 核心功能
1
🖱️
选中即收集
在任意英文网页选中单词或句子，右侧自动弹出"收集"按钮，一键保存到句游英语。
2
🎬
视频字幕收集
看 YouTube、Bilibili 等视频时，选中字幕即可收集，还能自动截取对应视频片段。
3
📦
一键转课程
收集的内容自动同步到句游英语，可一键生成私人课程包，随时练习六种模式。

📰
浏览英文网页
阅读英文新闻、博客、文档时，遇到不懂的句子随手收集。
📺
看 YouTube / Bilibili
刷视频时收集精彩台词、地道表达，附带视频片段。
💬
外文聊天 / 邮件
看到好的表达方式，选中即可保存到生词本或课程包。
📄
PDF / 电子书
PDF 阅读器同样支持，收集你喜欢的句子和段落。
🚀 三步安装 （Chrome / Edge 均可）
1
访问 Chrome 商店
打开 Chrome 浏览器，访问 Chrome 应用商店，搜索「句游小句子」。
2
点击"添加至 Chrome"
在插件详情页点击蓝色按钮，弹窗中确认"添加扩展程序"。
3
登录并开始收集
点击浏览器右上角插件图标，登录你的句游英语账号，即可开始收集。
